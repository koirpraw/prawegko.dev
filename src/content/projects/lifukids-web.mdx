## Overview

LifuKids Web is an interactive learning platform for children. Built with NextJS and TypeScript, it features gamified educational content, progress tracking for parents, and an engaging UI designed for young learners.

### Features

- **Interactive Lessons** — Bite-sized educational content with multimedia
- **Gamification** — Points, badges, and level progression
- **Parent Dashboard** — Track child's progress and time spent
- **Responsive Design** — Works on desktop and tablet
- **Content Management** — Admin panel for lesson creation

### Technical Details

- **Framework:** NextJS (Pages Router)
- **Language:** TypeScript (strict)
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL (via Prisma ORM)
- **Auth:** NextAuth.js with social providers
- **Deployment:** Vercel

### Status

Active development. Core learning modules and admin panel complete; working on multiplayer quiz feature.
