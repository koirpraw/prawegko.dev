## Overview

GoatReport is a mobile fitness tracking application built with Flutter. It helps users log workouts, track progress over time, set goals, and view detailed analytics. Named after the "GOAT" (Greatest Of All Time) mindset.

### Features

- **Workout Logging** — Log sets, reps, weight, and exercise type
- **Progress Tracking** — Visual charts and trends over time
- **Goal Setting** — Set short and long-term fitness goals
- **Analytics Dashboard** — Volume, frequency, and personal records

### Technical Details

- **Framework:** Flutter / Dart
- **State Management:** GetX with SQLite persistence
- **Charts:** fl_chart for progress visualization
- **Architecture:** Clean architecture with repository pattern
